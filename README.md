# Julian's Portfolio Website

A personal portfolio built with Angular to bring my professional career together in one place, showcasing my experience, projects, and skills, with a way to get in touch.

## Development

Run these commands from the project directory:

| Task | Command |
| --- | --- |
| Install dependencies | `npm ci` |
| Start the development server | `npm start` |
| Build for production | `npm run build` |
| Run unit tests | `npm test` |
| Generate a component | `npx ng generate component component-name` |

The development server runs at `http://localhost:4200/`. Production builds are saved to `dist/`.

See the [Angular CLI documentation](https://angular.dev/tools/cli) for more commands and options.
